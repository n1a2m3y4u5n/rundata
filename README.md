# RunData

**러닝 기반 현실세계 데이터 수집 플랫폼.** 달리는 사람이 지나간 자리의 데이터를 모아, 사람이 자주 안 가는 격자를 우선 채우도록 경로를 제안합니다.

**제19회 전국 학생 창업·발명 경진대회 창업부 우수상** (한국지식재산보호원, 2026-07-28) 출품작이자
**제2회 WISE 발명엑스포** 본선 부스 시연작입니다.

배포: **https://rundata-namyunsu.fly.dev**

## 핵심 설계

| 항목 | 값 | 어디에 |
|---|---|---|
| 지점당 체류 시간 | **25초** | `src/lib/engines/routing.ts` |
| 미관측 가중 | 경과일 기반 | 같은 파일 |

경로 제안은 **거리와 미관측 경과일을 함께 보는 비용 함수**로 만듭니다. 오래 안 본 격자일수록 가중치가 올라가되, 너무 멀면 뽑히지 않도록 거리로 눌립니다.

## 돌리기

```bash
npm install
npx prisma migrate dev
npm run dev
```

`.env` 가 필요합니다 (`DATABASE_URL`). 저장소에는 넣지 않았습니다.

## 이 저장소에 없는 것

공개용으로 정리하면서 뺐습니다.

- 대회 제출 서식 (`[서식1]` 계열), 발표 자료
- `dev.db` 개발용 데이터베이스, `.env`
- `public/samples/` 시연용 이미지 279장
- 참고용으로 받아 둔 외부 저장소 두 개
